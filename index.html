About me

I build things that actually work

Not a tutorial project, not a half-finished exercise — every repository here is a complete, runnable application.

I'm a B.Tech Information Technology student at Vinoba Bhave University, graduating in 2026. Most of my work has one idea behind it: software should work without asking for an account, without a cloud, and without a key that expires next week.

That is why the flagship project, Olmavax A.I, is a full multi-agent AI workspace that runs entirely on my own machine — with an offline brain that keeps working when there is no API key at all. Nineteen plugins, a QR encoder and a PDF writer are implemented from scratch rather than pulled from a package.

I care about the details that are easy to skip: XSS-hardened syntax highlighting, keyboard shortcuts, reduced-motion support, tests that actually run on every push.
