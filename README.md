### Repository layout

```
index.html                 the page
serve.js                   local preview server
package.json               scripts only, zero dependencies
assets/
  style.css                design system, layout, motion, print
  app.js                   rendering, filtering, command palette
  data.js                  all content — 11 projects, skills, stats
  banner.jpg               the banner graphic
downloads/                 generated PDFs and ZIP files
automation/
  build-docs.js            writes the CV and Resume PDFs directly
  build-package.js         builds the website-only archive
  build-full-package.js    builds the complete archive
  check-site.js            static checks
  profile_manager.py       profile README automation
```

### Commands

```bash
npm run dev       # start the preview server
npm run check     # run the static checks
npm run build     # regenerate the PDFs and both archives
```
